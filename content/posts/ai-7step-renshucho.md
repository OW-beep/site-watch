## この練習帳の使い方

AIが難しい依頼に答えるときの進め方を言葉にしたものが、[答え方の7ステップ](/posts/ai-shiki-7step)です。この練習帳では、その7ステップを、**人が、紙の上(または頭の中)で行う**練習をします。

| ステップ | やること |
|---|---|
| 1 | 依頼を言い直す |
| 2 | 足りない所を見つける |
| 3 | 小さな問いに分ける |
| 4 | 仮定を置く |
| 5 | 1つずつ答える |
| 6 | 検算する |
| 7 | 相手向けに並べる |

![7ステップ練習帳の図。友達の誕生日会、家計の見直し、週末の大掃除、発表資料、家族旅行の行き先の5つの依頼を、7ステップで分解する。](/images/zu-7step-renshucho.svg)

数字はすべて、練習用の仮のものです。答えが回答例と違っても、**仮定を説明できて、検算できていれば**、正しい解き方です。

## 練習問題

### 問題1:「友達の誕生日会を計画して」

「友達の誕生日会を計画して」という依頼を、7ステップで分解してください。

まず**自分の答えを紙に書いてから**、開いてください。

<details>
<summary>回答例と考え方を見る</summary>

**考え方の筋道**

1. **言い直す**:何を決めれば、計画になるのか
2. **足りない所**を探し、聞けるものは聞く
3. **分けて**、1つずつ答える
4. **検算**で、予算や時間を確かめる

**回答例**

| ステップ | この依頼では |
|---|---|
| 1 言い直す | 誰が、いつ、何人で、どんな雰囲気で祝うかを決めて、準備の手順にする |
| 2 足りない所 | 人数、予算、場所(家か店か)が不明。友達なので、あとで確認できる |
| 3 分ける | 場所/食事/飾り/連絡/プレゼント |
| 4 仮定を置く | 6人、1人2,000円、土曜の夜、自宅(いずれも仮) |
| 5 1つずつ答える | 食事は持ち寄り+ケーキを購入。飾りは簡単なものを少し |
| 6 検算 | 予算は12,000円(6人×2,000円)。ケーキ3,000円+食材6,000円+飾り1,000円=10,000円。2,000円の余裕がある |
| 7 並べる | 結論(自宅で持ち寄り、予算内)→ 内訳 → 次の一歩(今夜、全員に日程を確認する) |

</details>

### 問題2:「家計を見直して」

「家計を見直して」を、7ステップで分解してください。

まず**自分の答えを紙に書いてから**、開いてください。

<details>
<summary>回答例と考え方を見る</summary>

**考え方の筋道**

1. **言い直す**:どの支出を、いくら、いつまでに減らすのか
2. 足りない目標額や期間は、**仮定**する
3. 固定費と変動費に**分ける**
4. 減らす額を**足して**、目標に届くか確かめる

**回答例**

| ステップ | この依頼では |
|---|---|
| 1 言い直す | どの支出を、いくら、いつまでに減らすかを決める |
| 2 足りない所 | 目標額、期間、今の内訳が不明 |
| 3 分ける | 毎月ほぼ同じ「固定費」と、変わる「変動費」 |
| 4 仮定を置く | 月30万円を27万円(10%減)にする。期間は3か月(仮) |
| 5 1つずつ答える | 通信−0.5、保険−0.5、サービス整理−1.0、食費−0.5、光熱−0.3、日用品−0.2(単位:万円) |
| 6 検算 | 合計は−3.0万円で、目標の10%に届く |
| 7 並べる | 結論(月3万円の削減見込み)→ 内訳 → 次の一歩(今週、通信プランを確認する) |

</details>

### 問題3:「週末の大掃除を段取りして」

「週末の大掃除を段取りして」を、7ステップで分解してください。

まず**自分の答えを紙に書いてから**、開いてください。

<details>
<summary>回答例と考え方を見る</summary>

**考え方の筋道**

1. **言い直す**:何を、どこまで、何時間で終えるのか
2. 場所別に**分けて**、1か所の作業時間を見積もる
3. **検算**で、準備と片づけの時間も足す

**回答例**

| ステップ | この依頼では |
|---|---|
| 1 言い直す | 何を、どこまで、何時間で終えるかを決める |
| 2 足りない所 | 使える時間と、人数が不明 |
| 3 分ける | 場所別(キッチン、風呂、玄関、部屋) |
| 4 仮定を置く | 半日(4時間)、2人 |
| 5 1つずつ答える | 1か所1時間ずつ × 4か所 = 4時間分の作業。2人で分担すれば、約2時間 |
| 6 検算 | 準備と片づけに30分を足して、約2.5時間。半日(4時間)に収まる |
| 7 並べる | 結論(2人で約2.5時間)→ 分担表 → 次の一歩(道具を前日に出しておく) |

</details>

### 問題4:「来週の発表資料を作って」

「来週の発表資料を作って」を、7ステップで分解してください。

まず**自分の答えを紙に書いてから**、開いてください。

<details>
<summary>回答例と考え方を見る</summary>

**考え方の筋道**

1. **言い直す**:誰に、何を伝えて、何を決めてもらうのか
2. [資料のまとめ方](/posts/genba-shiryo-matome)の**5つの順番**で分ける
3. **検算**で、持ち時間に収まるか確かめる

**回答例**

| ステップ | この依頼では |
|---|---|
| 1 言い直す | 誰に、何を伝えて、何を決めてもらう発表かを決める |
| 2 足りない所 | 持ち時間と、聞き手が不明 |
| 3 分ける | 状況/問題/原因/対応/担当と期限 |
| 4 仮定を置く | 持ち時間10分、聞き手は管理者、1枚あたり2分 |
| 5 1つずつ答える | 結論1枚+状況と問題1枚+原因1枚+対応1枚+担当と期限1枚=5枚 |
| 6 検算 | 5枚 × 2分 = 10分。6枚にすると12分で超えるので、1枚にまとめる |
| 7 並べる | 結論を冒頭に、詳細は補足資料へ |

</details>

### 問題5:「家族旅行の行き先を決めて」

「家族旅行の行き先を決めて」を、7ステップで分解してください。

まず**自分の答えを紙に書いてから**、開いてください。

<details>
<summary>回答例と考え方を見る</summary>

**考え方の筋道**

1. **言い直す**:全員が納得できる、選び方の基準を決める
2. **判断軸**を決めて、点数で比べる
3. 重みを変えて、**検算**する

**回答例**

| ステップ | この依頼では |
|---|---|
| 1 言い直す | 全員が納得できるように、選ぶ基準を決める |
| 2 足りない所 | 予算、日数、季節が不明 |
| 3 分ける | 判断軸(費用、移動時間、見たいもの) |
| 4 仮定を置く | 予算10万円、2泊3日(仮) |
| 5 1つずつ答える | 候補を3つ挙げ、点数×重みで比べる([比較ツール](/tools/hikaku)) |
| 6 検算 | 重みを変えて、順位が入れ替わらないか確かめる |
| 7 並べる | 結論 → 理由 → 次の一歩(宿の空きを確認する) |

</details>

## 回答を見比べるコツ

- **ずれたステップを探す**:ステップ1(言い直し)が違うと、全部がずれます
- **ステップ2と4**(足りない所・仮定)を飛ばしていないか確かめる
- **ステップ6**(検算)は、飛ばしやすい。数字を合計し直す習慣をつける

## よくある質問

**Q. 7ステップ全部を、毎回やる必要がありますか?**

A. いいえ。簡単な依頼には不要です。迷う依頼や、答えが1つに決まらない相談のときに使ってください。

**Q. 時間がかかりすぎます。**

A. 最初は、ステップ1〜3だけで構いません。慣れたら、4〜7を足してください。

**Q. 仕事の依頼でも使えますか?**

A. 使えます。仕事での使い方は、[現場メモ](/category/genba)にまとめています。特に、[依頼を受けるときの確認](/posts/genba-irai-kakunin)は、ステップ1・2の実践例です。
