# Search Console の見方と、改善の回し方

## 1. 最初のデータ(2026-11-06 時点)
- 計測が始まったのは 11/3。表示回数は合計2回で、**傾向を読むには少なすぎる**
- ただし、1つだけ確かな手がかりがある
  - 実際に表示された検索語:「電気代 先月より 急に上がった 原因 調べる 方法」(掲載順位39位)
  - 表示されたページ:電気代の記事
  - → 読者は、**「悩み + 原因 + 調べる方法」という言い方**で検索している

## 2. この手がかりから、やったこと
- 電気代の記事を、検索語に近い題名・見出し・FAQに作り直し、料金のしくみを資源エネルギー庁の資料で確認して追記
- 同じ型の記事(水道代、スマホ代)を追加
- 悩み型の題名に、4記事を調整(書き出しメモ、判断軸と重み、3つの問い、売上が下がった原因)

## 3. 毎週見る場所(5分)
| 画面 | 見ること | 判断 |
|---|---|---|
| 検索パフォーマンス → クエリ | 新しく表示された検索語 | 読者の言葉。記事の題名・見出し・FAQに取り入れる |
| 検索パフォーマンス → ページ | 表示回数が多いページ | その記事を厚くする(FAQ、事例、出典) |
| 検索パフォーマンス → ページ | 掲載順位が11〜20位のページ | 2ページ目。内容の追加で、1ページ目を狙いやすい |
| ページのインデックス登録 | 「登録されていない」の理由 | 理由に応じて直す(クロール済み・未登録など) |
| サイトマップ | 送信済み・検出ページ数 | 記事数と合っているか |

## 4. 数字の読み方の注意
- 表示回数が数十回になるまでは、**順位やCTRの上下に一喜一憂しない**
- 順位は、検索のたびに変わる。**平均**で見る
- 新しいサイトは、評価が安定するまで、数週間〜数か月かかる

## 5. 次にやること
1. 新しい記事(水道代・スマホ代)を、Search Consoleの「URL検査」→「インデックス登録をリクエスト」
2. 2〜4週間後に、もう一度エクスポートして、新しい検索語を見る
3. 検索語に「原因」「調べる」「方法」を含む語が増えたら、同じ型の記事を増やす(食費、ガス代、通勤時間など)
