# SEO・コンテンツ計画(仮定)

※ 検索需要のデータは確認できていないため、以下は**仮定**です。公開後はSearch Consoleの「検索パフォーマンス」(クエリ・表示回数・クリック率)で必ず検証してください。

## 1. 想定する読者と困りごと(検索の意図)
| 困りごと | 想定する検索 | 受け皿ページ |
|---|---|---|
| 考えがまとまらない | 頭の整理 方法 / 書き出し | 書き出しメモ、3つの問い、/problems |
| 決められない | 優先順位 つけ方 / 比較 | 判断軸×重み、比較ツール |
| 数字の見積もり | フェルミ推定 例題 / 問題 | フェルミ推定入門、練習問題10選 |
| 原因が分からない | ロジックツリー 書き方 / 例 | ロジックツリー、電気代の例 |
| AIとの付き合い方 | AI 任せていいこと / AI 使い方 | AI式7ステップ、仕分けツール |
| 地頭を鍛えたい | 地頭 鍛える 方法 | 地頭を鍛える稽古10選(ハブ) |
| 通勤中・待ち時間に頭を使いたい | 頭の体操 大人 / 暗算 コツ | 頭の体操10選、暗算の3つの工夫 |
| 検索・AI時代に何を残すか | AI時代 考える力 | デジタルに負けない頭とは(入口記事) |
| 日記・手帳・読書ノート | 手書き日記 続かない / 読書ノート 書き方 | 稽古日誌4本 |

## 2. 実装済みのSEO対策
- 全記事に、固有のtitle・description・canonical、パンくず、構造化データ(Article・BreadcrumbList)
- トップに、WebSite・Personの構造化データ
- sitemap.xml、RSS、HTMLサイトマップ、内部リンク(1記事あたり平均6本以上)
- 悩み別ハブ(/problems)、レベル別・テーマ別一覧、地頭10選のハブ記事
- 画像に幅・高さ・alt、遅延読み込み
- 検索クエリになりやすい題材を、練習問題つきの記事(フェルミ推定10選)にした

## 3. タイトル・見出しのルール(今後の記事)
- タイトルは、読者の困りごと・疑問を先頭に(例:「◯◯が決められないとき」「◯◯の例題10選」)
- 1記事1テーマ。h2は5〜8個、h2に読者の疑問の言葉を入れる
- 冒頭の「今日の要点」で、結論を先に書く
- 末尾に、FAQ(読者の疑問3問)、関連稽古へのリンク
- 医療を連想する語(予防・改善・効果の断定など)は使わない

## 3b. 言葉づかいの方針(一般の人向け)
- 入口(タイトル・冒頭)は、日常の言葉で書く。専門用語は「この考え方を、〇〇と呼びます」と、あとから名前を添える
- 例:「ざっくり計算(フェルミ推定)」「原因をしぼり込むツリー(ロジックツリー)」
- 用語は、記事の「用語メモ」と、用語集ページで説明する

## 4. 次に書く記事のバックログ(優先順)
| 優先 | 記事案 | 理由 |
|---|---|---|
| 1 | ロジックツリーの練習問題10選 | フェルミ10選と同型。検索の受け皿になりやすい |
| 2 | MECEの練習問題(身近な題材で) | 構造化の需要に対応 |
| 3 | 手書き日記の始め方ガイド(3行テンプレ・続け方) | 「手書き日記 書き方/続かない」への受け皿。体験記事と相互リンク |
| 4 | 優先順位のつけ方:やることが多すぎるとき | 悩みナビの上位テーマ |
| 5 | 稽古日誌:手書き日記30日チャレンジの1週間後の報告 | 一次体験。開始宣言と連動(実際にやった後に) |
| 6 | 会議・打ち合わせの前に書く3行メモ | 現場メモの続編 |
| 7 | 頭の体操:言葉あそび編(しりとりの発展形、なぞなぞ型の問い) | 「頭の体操」の検索に対応。回答例つき |
| 8 | 頭の体操:数あそび編(暗算の続き、数の見当) | 暗算の記事から回遊 |
| 9 | 家族で遊べる頭の体操(2人以上でできる問題) | 滞在時間・共有されやすさ |

## 5. 計測と見直し(公開後)
- **1か月後**:Search Consoleで、表示回数の多いクエリと、掲載順位が11〜20位の記事を確認する。該当記事に、FAQや事例を足す
- **クリック率が低い記事**:titleとdescriptionを、読者の言葉に書き換える
- **審査中・直後**:URLは変更しない(変更が必要なら、リダイレクトを設定する)
